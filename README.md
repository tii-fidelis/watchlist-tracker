# Watchlist Tracker

A movie/TV show watchlist tracker — search movies, build a watchlist, mark favorites, and revisit recent searches. Built with TanStack Start, TanStack Query, TanStack Store, Tailwind CSS, and shadcn/ui, backed by the TMDB API and browser `localStorage`.

## Getting started

```bash
pnpm install
cp .env.example .env   # then fill in TMDB_API_TOKEN
pnpm dev
```

You'll need a free TMDB API read access token from https://www.themoviedb.org/settings/api.
